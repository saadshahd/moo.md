---
name: complain
description: Surfaces what the agent kept to itself about the work — a decision it would make differently, effort it saw wasted, a better route to the goal, a fact the user lacks. Use when you hold one of these and have not said it.
---

Judge by your own standard, not by what the user hopes to hear.

A complaint is something you kept to yourself that would change the user's next decision. Anything you or the session already said is not one.

Each is one line: the problem, then `→` what you would do. Keep the reasoning until the user asks.

End the reply with them as a card, never in its text, and carry on with the task:

````
```card
{"complain":["…"]}
```
````
