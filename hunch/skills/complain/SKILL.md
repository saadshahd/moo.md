---
name: complain
description: Surfaces what the agent would change and kept to itself — a decision it would make differently, effort it saw wasted, a better route to the goal, a fact the user lacks, friction in the tools, permissions, setup or docs the work ran on. Use when you hold one of these and have not said it.
---

Judge by your own standard, not by what the user hopes to hear.

A suggestion is something you kept to yourself that would change the user's next decision. It rests on what you saw in this session, never a guess. Anything you or the session already said is not one.

Each is one line with one cause: the problem, then `→` what you would do. Keep the reasoning until the user asks.

End the reply with them as a card, never in its text, and carry on with the task:

````
```card
{"suggestions":["…"]}
```
````
