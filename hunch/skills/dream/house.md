## The owner's rules

These win over any other instruction about what to keep.

- **What earns a note.** A fact that took effort and matters: a decision the code doesn't show, a hard-won correction, a measured finding, or a rejection with its reasons. A note whose loss would cost nothing that can't be cheaply re-derived from CLAUDE.md, the repo, git, or public docs is deleted.
- **History stays.** A note that records a past decision, a measurement, a rejection, or dropped work stays even when the code or files it names are gone. A missing path alone never makes a note stale.
- **Fix the line, keep the note.** When one line of a note is false now (a file "on disk" that was deleted, a hook named as an example that no longer exists) but its lesson holds, edit that line and keep the note.
- **Delete only with a source.** Delete or rewrite a note as wrong only when a file, commit, or newer note proves it wrong.
- **Stay inside the memory directory.** Never edit CLAUDE.md or any file outside the memory directory.
