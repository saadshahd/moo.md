# Repeated move

Steps the user walked the agent through more than once.

**Sign:** two or more USER turns, in this session or across the turns of one flow, that give the same steps: an order, a check, a place to look, a thing never to do.

| Counts | Doesn't |
|---|---|
| The same steps, given again in new words | The same request for new work ("do the next one") |
| Steps an installed moo skill already carries, given by hand → a misfire or missed move, file it there | One-time facts about this project |

**Evidence:** every USER turn that gives the steps, and the steps in the user's words as they pass `scrub.sh`.
