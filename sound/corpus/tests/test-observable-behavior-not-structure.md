A test asserts what the code does for a caller, never how it does it internally — if renaming a private helper breaks the test, the test is wrong, not the rename — and it drives and reads the code through handles a caller has: an accessible role and name, a data attribute, a route, JSON output, never coordinates, tab order or generated markup. Doubles belong only at a seam you own (your integration-point adapter over a paid API, a queue, the clock), never over your own internals or a third party's. A test verifies nothing when its answer was settled before the code ran: an expected value derived from its own stubs (it asserts the mock, not the code), computed by the same logic as the code under test (a wrong result still passes), or already proven by the type checker. The check: break the behavior the test guards — if the test still passes, rewrite or delete it.
_Avoid_: `jest.spyOn` on your own module, `toHaveBeenCalledWith` against internal collaborators, snapshot tests of intermediate objects, testing private/unexported functions directly; a mock whose configured return value is the same value the test then asserts (a tautological mock); doubling a third-party library's internals instead of your own adapter over it; `expect(typeof x).toBe('string')` on a typed value; an expected value computed by calling the module under test; a selector on a generated class name or `nth-child`, or a click at a screen coordinate.
Detect: a test importing something not exported from the module's public surface, or asserting call counts/arguments on a function defined in the same package under test; a test whose expected value is fully determined by a stub's configured return or computed by the module under test, so nothing of the code under test is actually exercised; an assertion the type checker already proves; a selector on generated markup or a screen position. Then break the guarded behavior (invert a condition, return early): a test that still passes is the finding.
Not-when: the double stands at a seam you own — your typed adapter over a paid API, a queue, the clock (integration-point-isolation gives you that seam) — that's the sanctioned place for a fake; the ban is on doubling your own internals, or a third party's internals directly instead of your adapter over it.
