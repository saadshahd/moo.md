Code whose cognitive complexity — SonarSource's measure: one point for each break in straight-line flow, and one more for each level of nesting that break sits in — is 5 or less gets no test aimed at it: the tests of the code that calls it already run it, and a direct test repeats them. The score covers everything the test runs of the repo's own code: the function it calls, the functions defined inside that function, and the repo's functions those reach that the test does not fake. A regular expression in that code takes the test out of the rule — a regex literal, a `RegExp`, or a regex constant the code references — since a pattern hides branches the score cannot count.
_Avoid_: a test file for a three-line formatter, mapper, getter or one-branch guard; `it('returns the full name')` calling `fullName(user)` directly when the test of the code that renders the name runs the real `fullName`.
Detect: for each test, name each function it calls whose result or effect an assertion checks; read the cognitive complexity of each from a measuring tool, never by eye, summed as above; the test is the finding — delete it — when every such sum is 5 or less, no regular expression is in that code, and a test of a caller in the suite runs the same function unfaked.
Not-when: no test of a caller runs the function unfaked — an export only code outside the repo calls, or a function every caller's test fakes — so the direct test is the only one that runs it; or the function makes a claim a law rule's own `Detect:` recognizes — an encode/decode pair, an operation named safe to repeat, a transform under a stated invariant — where the law's property test stays and the function's example tests are rewritten into it, never deleted.
Cross-ref: roundtrip-encode-decode-is-a-law, idempotence-of-repeatable-operations, invariant-preservation-over-mutation — the laws that outrank the score; test-observable-behavior-not-structure — tests reach code through the handles its callers use, which is why callers' tests are where simple code gets run.
