Running only the tests a diff can reach claims the reach map is complete, and a wrong map fails silent: CI goes green on code no test ran. So selection is trusted only after a real change hidden from the map turned CI red, and it narrows only the feedback on a change under review — the full suite gates every merge into the main branch.
_Avoid_: an affected-only or changed-files-only run as the check that gates a merge into main (a merge queue, a required status); selection switched on with no record of a planted change that turned CI red; a path filter on a test workflow whose list leaves out files the tested code reads.
Detect: CI config that narrows which tests run by the diff (an affected-projects command, a changed-files or related-tests flag, a path filter on a test workflow) that gates a merge into main; or a diff that adds or widens such narrowing and records no planted change that turned CI red.
Not-when: the narrowing only splits the suite across machines, so every test still runs and no map can be wrong; or a path filter lists every file the workflow's tests read, shown by the code's imports and file reads, never by folder names.
