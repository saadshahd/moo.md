Fit a new requirement by redesigning as if it had been a founding assumption, never by bolting it on beside the design that missed it — and first read every file the requirement touches, so the redesign covers all of them.
_Avoid_: a new requirement entering as a branch on one value, a flag parameter only one caller passes, or a special-case early return in code whose other paths stay as they were; a redesign that leaves a file handling the same concept on the old shape.
Detect: a diff whose new behavior sits in a guard, flag or special case around an unchanged core, where the core's types or names do not mention the new requirement; or a redesign that changes a concept's shape in some files while another file handling that concept keeps the old one.
Not-when: the requirement is one-off and dated to go (a migration shim with its removal scheduled — atomicity-three-regimes); or the existing design already models the requirement and the branch is its natural case.
