A behavioral boolean prop that adds variant behavior to a component — `loading?`, `fullWidth?` — is a composition concern, not a prop. "Loading support" is a SEPARATE wrapper component. `fullWidth` is a CSS class or a `<FullWidth>` layout wrapper. Compose through `children` and slots (`React.ReactNode`).
_Avoid_: a base component that grows variant behavior through boolean toggles instead of wrappers and slots.
Detect: grep component props types for `loading?: boolean`, `fullWidth?: boolean` and other behavioral boolean fields that switch on a variant — each should be a wrapper component, a CSS class, or a slot instead.
Not-when: the prop forwards a native HTML attribute the DOM already defines (`disabled` on `<button>`, `<input>`, `<select>`, `<fieldset>`; `readOnly`, `required`) — a component passing one through to its underlying element is the standard idiom and needs no wrapper; or discriminated unions over a domain model's own props — the ban is on behavioral variant toggles, not on modeling genuine domain states, and not on variant props where a discriminated union's narrowing tax would exceed its benefit.
