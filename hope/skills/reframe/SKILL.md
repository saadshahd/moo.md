---
name: reframe
description: Restate a problem off the framing it arrived in. Use when a framing came by default, not by choice — every option inside it loses, or an ask names a step or an artifact and leaves the outcome it serves unnamed.
---

This runs inside one turn — nothing waits on the user.

1. Name what the current framing fixes: its subject, its level, its scope.
2. Change exactly one and state the problem again with that one change — one plain sentence. Where more than one change would do, prefer the statement that makes the stuck options irrelevant over the one that picks between them.
   - The ask names a step → raise its level to the goal past it: what the user wants to happen next, not the step's own result.
   - The ask names an artifact → change its subject to what the artifact must do: the verb, who it acts on, and the limit it works within.
3. Test the new statement before delivering anything: if it names the same subject at the same level, it is the old frame in new words — discard it, change a different one of the three, and state and test once more. If the second statement fails the same test, the framing resists reframing — carry that verdict out as the result instead of a statement.

Deliver the new statement with one line on what it frees that the old framing blocked. Stop there.

If the reworking ended with the framing resisting reframing, hand back that verdict instead — name the changes tried, and let no statement stand as movement when the test showed none.

An option inside the framing can actually win → the frame holds; answer inside it. The user chose the frame, or the thing asked for is itself the end they want → answer inside it. Something exists inside the frame and a claim about it needs a committed verdict → use **judge** skill. The frame is fine and the user is missing something already settled → use **explain** skill.
