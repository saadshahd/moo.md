Turn something the user holds but can't express into the user's situation, on the record.

## Needs

The user holds something — a taste, an unease, a half-formed idea — they can't yet put into words.

## Gives

The user's situation, on the record, in words the user confirmed as theirs.

## Turns

`open`
- **Advances:** each reaction to what was offered — a yes, a no, a "closer but".
- **Retires:** a new offer stops changing the record, or the user says the record matches what they hold.

## Wrong move if

A plain question would have worked → **Clarify**.
The user is missing something settled, not holding something unsaid → **Explain**.

## Prompt

```md
Held: <what the user seems to hold but cannot express>

Draw it out interactively. Offer one concrete thing the user can react
to — a candidate, a contrast, a small set to pick apart — never a list
of questions and never abstract choices they haven't experienced.

One offer per turn. Read the reaction, adjust, offer the next.
Keep what each reaction confirmed on the record, in the user's own words.

Retire when a new offer stops changing the record, or the user says
the record matches what they hold. If a reaction shows they'd answer
a direct question, ask it — don't keep staging.
```
