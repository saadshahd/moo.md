# Hold

A **hold** move takes something that already exists and hands back what a human works through at their own pace, until they can say how it works with the agent out of the room.

## The moves

|           | Needs                                                                   | Gives                                                                                    | The agent is in the wrong one if                                                                       |
| --------- | ----------------------------------------------------------------------- | ---------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------ |
| **Grasp** | a change or a state someone else built                                  | the system as it was → the idea → the code → a quiz to pass before shipping              | the reader lacks how it behaves → **Toy**; the reader is an audience → **Land**                        |
| **Toy**   | a behavior that reading has not made intuitive                          | a world the human drives: state visible, time scrubbable, each effect beside its cause   | the reader wants what changed → **Grasp**; the world is the product → not a move                       |
| **Land**  | knowledge, and an audience (the user counts) that must keep one thing of it | that one thing, carried by visuals, stepped at the audience's pace                    | the audience is the user and the knowledge is a change → **Grasp**, a behavior → **Toy**               |

## Settled

|                |                                                                                                           |
| -------------- | --------------------------------------------------------------------------------------------------------- |
| Grasp's Needs  | a change or a state: a repo joined is a state someone else built                                          |
| The quiz alone | Grasp's last step, not a move                                                                             |
| Essence        | decision procedures, content strategy, reveal choreography; scaffolding and canvas code regenerate on demand |
