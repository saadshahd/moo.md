# Refit moves

A **refit** re-derives something already stated — same grounds, different objective. If the grounds moved, it is a new derivation, not a refit.

Run it until a case stops fitting, then back off by the minimum. What ships always fits every case in the grounds; the overshoot is a probe, never a deliverable.

|              | Objective | Needs                                            | Gives                                         | You're in the wrong one if                                    |
| ------------ | --------- | ------------------------------------------------ | --------------------------------------------- | ------------------------------------------------------------- |
| **Widen**    | weakest   | a rule that decides only the cases it came from  | the broadest rule still sound on them         | nothing unseen will ever meet it → **Compress**               |
| **Compress** | shortest  | a closed set — nothing unseen is coming          | the shortest statement that covers it         | something unseen will meet it → **Widen**                     |
| **Anchor**   | checkable | a rule that needs the reader's judgment to apply | the same rule, applied the same way by anyone | it decides fewer cases afterward → you narrowed, not anchored |

## Widen

```md
Cases: <...>

Do not summarize these. Induce the widest rule that
(a) gets every case above exactly right, and
(b) forbids the wrong answer in each.

Then:

1. List 10 situations NOT in my cases where this rule gives a definite answer, and state the answer it forces in each.
2. Find one situation where it forces a WRONG answer. If you find one, narrow the rule by the smallest amount that fixes it, and repeat.

Prefer the rule that decides more situations, even if it takes longer to state.
```
