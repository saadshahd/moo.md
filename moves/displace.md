# Displace

A **displace** moves a problem off its current framing. The deliverable is a new statement of the problem.

|                 | Needs                                          | Gives                                                         | It didn't fire if                                          |
| --------------- | ---------------------------------------------- | ------------------------------------------------------------- | ---------------------------------------------------------- |
| **Reframe**     | a framing that feels forced ("must be X or Y") | the problem stated about a different subject, level, or scope | the new statement names the same subject at the same level |
| **Inversion**   | a goal you keep failing to reach head-on       | the route to guaranteed failure, negated                      | you got a list of risks rather than a route                |
| **Shift**       | a problem stated in one domain's vocabulary    | the same problem in a distant domain's terms                  | the other domain's terms map one-to-one onto yours         |
| **Provocation** | an obvious answer you cannot see past          | movement extracted from a statement you know is false         | you would defend the statement — that's a proposal         |
